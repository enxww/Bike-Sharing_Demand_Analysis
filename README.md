# Bike-Sharing Demand Analysis

An end-term Statistics and Data Science project that examines bike-sharing demand through exploratory analysis, Bayesian inference, time-series forecasting, Markov-chain modelling, and machine-learning workflows.

## What is included

- `SDS2_elnur_endtem (1).ipynb` — the complete analysis notebook
- `SDS2_Elnur_Endterm_Report (1).pdf` — the accompanying report

## Analysis workflow

1. Acquire and prepare the bike-sharing dataset
2. Clean data and explore hourly, monthly, and weather-related demand patterns
3. Apply Bayesian inference to describe demand
4. Forecast demand with a SARIMAX time-series model
5. Model transitions with a Markov-chain approach
6. Compare machine-learning models for predictive performance
7. Summarise findings, limitations, and practical implications

## Quick start

Create a Python environment and install the project dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook
```

Then open `SDS2_elnur_endtem (1).ipynb`.

## Requirements

The notebook uses Python with NumPy, pandas, Matplotlib, SciPy, scikit-learn, statsmodels, and Jupyter. Exact installable dependencies are listed in `requirements.txt`.

Created as an end-term project for Statistics and Data Science. The repository is organised so visitors can start with this overview, review the notebook, and then consult the report for the full narrative and results.
